# /summarize — Session handoff

Produce a handoff note for the next chat or teammate.

## Output format

```markdown
## Goal
(one sentence)

## Done this session
- ...

## Key files touched
- `path` — why

## Tests / verification
- [ ] what ran and result

## Blockers / open questions
- ...

## Next step
(one concrete action)
```

Keep it under one screen. No secrets.
