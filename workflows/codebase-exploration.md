# Codebase exploration

## First 15 minutes in a new repo

1. Read `README.md` and `CLAUDE.md` (if present).
2. Skim `package.json` / `pyproject.toml` for scripts.
3. Find `tests/` or `*.spec.ts` — tests document behavior.
4. Ask Claude: `/analyze` with "Where is X handled?" for your feature area.

## Questions that work well

- "What runs when the app starts?"
- "Where are API routes defined?"
- "What tests cover [feature]?"
