# Example: Fix a broken test

## Goal

Make a failing test pass without disabling it.

## Setup

In your practice repo, introduce or use a test that fails (wrong assertion or broken import).

## Steps

1. Run tests; copy failure output.
2. `/explain` the error.
3. `/analyze` the code under test.
4. `/fix` with smallest change.
5. Re-run tests.

## Done when

Test passes and you can explain the root cause in one sentence.
