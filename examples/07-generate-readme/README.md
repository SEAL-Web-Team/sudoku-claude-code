# Example: Generate a README

## Goal

Write a README that helps a beginner run your project in 15 minutes.

## Sections

- What it does
- Prerequisites
- Install
- Run / test
- Project layout (short)
- How to contribute

## Steps

1. Run the project yourself; capture exact commands.
2. Ask Claude to draft README from your notes.
3. Edit for accuracy; remove hallucinated scripts.

## Done when

A teammate clones and runs successfully without asking you.
