# Example: Deploy a simple app (conceptual)

## Goal

Understand how CI/CD connects to deployment — not production deploy on day one.

## Steps

1. Read [`github-actions/README.md`](../../github-actions/README.md).
2. Identify build + test jobs in a sample workflow.
3. List what secrets a real deploy would need (do not commit them).
4. Discuss with mentor where SEAL apps actually deploy.

## Done when

You can draw: push → CI → artifact → deploy, and name what runs at each step.

Full production deploy is out of scope for week one; focus on **test in CI**.
