Hands-on exercises adapted for SEAL Sudoku students. Each maps to the quest loop and a workshop module.

| Example | Skill focus | Workshop tie-in |
| --- | --- | --- |
| [01-build-crud-app](01-build-crud-app/README.md) | Plan → implement → test | Modules 4–5 |

| [03-generate-api-docs](03-generate-api-docs/README.md) | Documentation | Module 3 |
| [04-add-frontend-feature](04-add-frontend-feature/README.md) | Frontend + review | Module 4 |
| [05-automate-browser-workflow](05-automate-browser-workflow/README.md) | Playwright | Module 6 |
| [06-review-pr-with-claude](06-review-pr-with-claude/README.md) | Review workflow | Module 8 |
| [07-generate-readme](07-generate-readme/README.md) | Docs | Module 1 |
| [08-deploy-simple-app](08-deploy-simple-app/README.md) | CI basics (conceptual) | Module 5 |

Start with **07** or **02** if you want a single sitting under one hour.
