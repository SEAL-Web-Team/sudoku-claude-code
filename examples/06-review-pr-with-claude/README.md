# Example: Review a PR with Claude

## Goal

Practice review before asking a human reviewer.

## Steps

1. Open your PR diff on GitHub or run `git diff main...HEAD`.
2. `/review` with the PR description pasted.
3. Cross-check [review-checklist](../../docs/best-practices/review-checklist.md).
4. Fix critical/major items.
5. Walk [ship-checklist](../../workflows/ship-checklist.md) before requesting review.
6. Request review from quest task reviewer.

## Done when

Self-review notes are addressed and checklist in PR template is complete.
