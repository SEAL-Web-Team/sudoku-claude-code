# Architecture explainer

Produce:

1. **Purpose** — one paragraph
2. **Components** — bullet list with paths
3. **Data flow** — numbered steps
4. **Boundaries** — what this system does *not* do

Use ASCII or mermaid only when it clarifies; keep diagrams small.
