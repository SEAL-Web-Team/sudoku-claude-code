# Debugging

1. Capture exact error text and reproduction steps.
2. Form hypotheses; read code to confirm or reject.
3. Change one thing at a time; re-run the same test/command.
4. Explain the root cause in plain language when fixed.

Never disable tests or hide errors without user approval.
