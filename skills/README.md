# Agent skills (beginner-safe)

Curated skills for Sudoku students. Copy a folder into your project `.cursor/skills/` or user skills directory.

| Skill | Purpose |
| --- | --- |
| [code-review](code-review/SKILL.md) | Review diffs for bugs and missing tests |
| [debugging](debugging/SKILL.md) | Systematic error investigation |
| [playwright](playwright/SKILL.md) | Browser test authoring |
| [frontend-dev](frontend-dev/SKILL.md) | React/Next UI changes |
| [backend-api](backend-api/SKILL.md) | API routes and data flow |
| [test-writing](test-writing/SKILL.md) | Unit and integration tests |
| [documentation](documentation/SKILL.md) | README and tutorial writing |
| [architecture-explainer](architecture-explainer/SKILL.md) | High-level system maps |
| [onboarding-assistant](onboarding-assistant/SKILL.md) | First-day repo orientation |

We intentionally omit multi-agent swarm orchestration from the beginner track.
