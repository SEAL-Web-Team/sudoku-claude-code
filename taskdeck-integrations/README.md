# taskdeck integrations

**taskdeck** is SEAL's JavaScript automation platform with Claude and Playwright. This folder links workshop content to taskdeck patterns without vendoring the private repo.

## Learning path

1. [`claude-templates/CLAUDE.taskdeck.md`](../claude-templates/CLAUDE.taskdeck.md) — copy into taskdeck branches when contributing.
2. [`playwright/`](../playwright/README.md) — browser tests using the same primitives.
3. [`examples/05-automate-browser-workflow`](../examples/05-automate-browser-workflow/README.md) — guided exercise.

## What to study in taskdeck (internal)

When you have repo access, search for:

- Playwright config and `*.spec` files
- Claude API or agent invocation helpers
- Google Sheets / Workspace connectors (if used in your quest)

## Workshop constraint

Do not copy taskdeck secrets, service accounts, or internal URLs into this public workshop repo.
