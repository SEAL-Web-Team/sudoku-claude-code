# Onboarding (Sudoku students)

Welcome to the SEAL Sudoku Claude Code workshop repository.

## Day 0 checklist

- [ ] GitHub access to SEAL-Web-Team (ask mentor)
- [ ] Claude Code or Cursor installed
- [ ] Read [README](../README.md) and [beginner track](../beginner-track/README.md)
- [ ] Join project Slack channel (link in team YBR)

## Day 1 (about 2 hours)

1. Workshop module [01](workshops/01-introduction-to-claude-code.md)
2. Copy [`claude-templates/CLAUDE.SEAL.md`](../claude-templates/CLAUDE.SEAL.md) into a practice repo as `CLAUDE.md`
3. Install [slash commands](../slash-commands/README.md)
4. Try example [07-generate-readme](../examples/07-generate-readme/README.md)

## Quest loop

Read → plan → fix → test. Use `/plan` and `/test` until it is habit.
