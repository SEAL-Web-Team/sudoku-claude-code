# Context management

## When context gets large

- Start a new chat for a new sub-task
- Use `/summarize` and paste the handoff into the next session
- Keep a `HANDOFF.md` in your branch (gitignored if personal)

## Handoff template

```markdown
Goal:
Done:
Next:
Blockers:
Files:
```

## Proactive compaction

After completing a milestone, ask: "What should the next session know in under 200 words?"

Do not rely on the model remembering earlier chats.
