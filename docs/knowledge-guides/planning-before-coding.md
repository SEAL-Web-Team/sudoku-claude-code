# Planning before coding

Planning prevents wasted diffs and scary PRs.

## Minimum plan (3 bullets)

1. What changes
2. How to verify
3. What you will not touch

## Workflow

See [`workflows/plan-first.md`](../../workflows/plan-first.md) and slash command [`/plan`](../../slash-commands/plan.md).

## SEAL quest alignment

Reviewers expect: read codebase → plan → fix → test. The plan is evidence you read first.
